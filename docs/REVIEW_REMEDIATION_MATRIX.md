# Review Remediation Matrix

## Purpose and status vocabulary

This is the authoritative closure register for the July 2026 overall flaws and
limitations assessment, `AUTHOR_REVIEW.md`, and the requirements in
`CODEX_MASTER_REMEDIATION_PROMPT.md`. The baseline was rechecked against
`origin/main` at `ce6d805afba27c2550da2ca58d1f844793ea25a8`; the remediation
branch initially differed only by the committed master prompt at
`649244552f4d68fc49bcc6d35a94e99e4e638dd8`.

Statuses have precise meanings:

- `confirmed / pending`: reproduced at baseline and not yet remediated;
- `already_fixed`: the earlier finding no longer reproduces and current evidence
  demonstrates the correction;
- `changed since audit / pending`: the original evidence changed, but the
  underlying requirement is still open;
- `closed`: implemented and verified by the listed evidence;
- `mitigated by claim reduction`: the software limitation remains, but the
  unsupported claim has been removed and the residual limitation is explicit;
- `external-only`: only an institution, rights-holder, venue, or named author
  can legitimately supply the remaining attestation.

No item may be marked closed from a plan, source inspection, or passing unit
test alone when the requirement calls for executed experiments or rendered
artefacts. Final evidence paths and commands will replace `pending` entries as
each phase is completed.
